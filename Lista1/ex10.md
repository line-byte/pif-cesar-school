Alternativa correta:
    b) Verdadeiro (a linguagem C diferencia rigorosamente letras maiúsculas de minúsculas).

Na linguagem C, letras maiúsculas e minúsculas são diferenciadas. Isso significa que `peso`, `Peso` e `PESO` são identificadores diferentes e, portanto, não representam a mesma variável.
    Por exemplo:
        ```c
        int peso;
        int Peso;
        int PESO;
        ```

Nesse caso, existem três identificadores diferentes. Portanto, é necessário manter atenção à utilização de letras maiúsculas e minúsculas durante a escrita do programa.
