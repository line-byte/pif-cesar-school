| Instrução         |Status (C/I)| Justificativa Teórica                                            |
| ----------------- |------------|----------------------------------------------------------------- |
| `int a;`          | Correto    | `int` é um tipo de dado válido em C para declaração de variáveis   inteiras.                                                                                           |
| `float b;`        | Correto    | `float` é um tipo de dado válido em C para declaração de variáveis  de ponto flutuante.                                                                                 |
| `double float c;` | Incorreto  | `double` e `float` não podem ser combinados dessa forma. Para maior precisão, deve-se utilizar `double c;`.                                                             |
| `unsigned char d;`| Correto    | `unsigned` pode ser combinado com `char`, formando o tipo `unsigned char`.                                                                                              |
| `unsigned e;`     | Correto    | `unsigned` sozinho equivale a `unsigned int`.                                                                                               |
| `long float f;`   | Incorreto  | `long` não pode ser combinado com `float`. A combinação válida é `long double`.                                                                                      |
| `long g;`         | Correto    | `long` sozinho equivale a `long int`.                                                                                               |
| `long double h;`  | Correto    | `long double` é uma combinação válida em C para variáveis de ponto flutuante.                                                                                          |
